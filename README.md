## 云端验证

所有开发和验证在本健身专属云环境内完成，不要求用户电脑运行。使用已有 Node、Playwright 和 Chromium，无依赖安装或编译步骤，不新增 GitHub 托管测试。

```bash
node --test tests/*.test.cjs
node scripts/check-sync-config.cjs
```

要求恢复同步的交付必须另跑以下门禁；当前因没有获授权的同步服务，按预期返回状态码 2，不能当作生产同步可用：

```bash
node scripts/check-sync-config.cjs --require-sync
```

浏览器回归需要分别在两个终端启动仅监听云端回环地址的服务：

```bash
python3 -m http.server 18741 --bind 127.0.0.1
python3 scripts/serve-review.py
```

然后运行：

```bash
node tests/run-cloud-browser.cjs
node tests/cloud-sw-browser.cjs
```

隔离演示服务将记录键与同步 fixture 仅在响应内替换，磁盘生产源码及公开配置不变。普通页面的同步回归也仅通过测试中的内存响应 fixture 配置模拟接口，禁止覆盖产品 SYNC。所有数据为合成，外部请求阻断或模拟，既有同步读写脚本不作为测试运行。

实际 SW 检查自带回环 18743 服务，从发布基线 `c4c13bd` 升级到候选版，验证离线、数据保留和真实 Cache.put 配额失败。输出为 `output/playwright/`，该目录不纳入提交。
